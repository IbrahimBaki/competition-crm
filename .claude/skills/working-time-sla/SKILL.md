# وقت العمل (Working Time) — مبني على BE-02

## القاعدة الذهبية
**كل** حساب لمدة/فرق وقت مرتبط بالـ SLA لازم يعدّي على خدمة واحدة مركزية (`WorkingTimeService` أو المكافئ)، مش `now()->diffInMinutes()` مباشر.
السبب: SLA وescalation والتقارير والأتمتة المجدولة لازم يتفقوا على نفس الرقم دايمًا.

```php
// ❌ ممنوع
$elapsed = now()->diffInMinutes($ticket->created_at);

// ✅ صح
$elapsed = app(WorkingTimeService::class)->elapsedWorkingMinutes(
    $ticket->created_at, now(), $ticket->branch
);
```

## قواعد أساسية
- كل التخزين بالـ UTC. التحويل للـ timezone بتاع الفرع يحصل فقط عند العرض/الحساب، أبدًا مش عند التخزين.
- التقويم بياخد في الاعتبار: أيام العمل الأسبوعية (تدعم أسبوع أحد-خميس)، الإجازات الرسمية (متكررة أو لمرة واحدة)، ومنطقة زمنية IANA لكل فرع.
- تقويم 24/7 هو إعداد مدعوم وليس حالة خاصة في الكود.
- تغيير تقويم فرع **لا يغيّر بأثر رجعي** أي وقت متحسّب ومسجّل قبل كده.

## سيناريوهات اختبار إلزامية (golden tests)
لازم تعدي كلها قبل ما تعتبر أي منطق SLA "خلص":
- [ ] حساب عبر الليل (overnight)
- [ ] حساب عبر عطلة نهاية أسبوع
- [ ] حساب عبر إجازة رسمية
- [ ] حساب عبر تحويل توقيت صيفي/شتوي (DST)
- [ ] بداية وقت خارج ساعات العمل
