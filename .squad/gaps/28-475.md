## Architecture Decisions Made

1. **SLA Reconciliation**: Reports read persisted `elapsed_minutes` from `ticket_sla_clocks.elapsed_minutes` — never `diffIn()` or time arithmetic. Enforced by `NoSlaRecalculationTest` scan.

2. **Timezone Handling**: UTC storage + SQL-layer conversion via `CONVERT_TZ`. Request specifies timezone; response echoes it back so caller knows what was applied.

3. **Scoping Before Aggregation**: `ReportScopeResolver` narrows filter *before* query execution. Queries only see rows the user is authorized for. No post-filter on aggregates.

4. **Half-Open Intervals**: `[from, to)` where `to` is exclusive. Makes "this month" and "this day" reconcile without off-by-one errors.

5. **Export Threshold**: Sync rendering ≤5000 rows (configurable); above threshold dispatches job, returns 202, never blocks HTTP request.
