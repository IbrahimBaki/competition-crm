# Story 470 Implementation Gaps & Blockers

## BLOCKER: Pre-Existing Migration Issue: quick_replies Foreign Key

**Issue:** Migration `2026_08_27_170300_create_quick_replies_table.php` (pre-existing, not created by Story 470) fails with foreign key constraint error:
```
SQLSTATE[HY000]: General error: 3780 Referencing column 'department_id' and referenced column 'id' 
in foreign key constraint 'quick_replies_department_id_foreign' are incompatible.
```

**Root Cause:** The `quick_replies` table's `department_id` is created as `foreignId()` (unsigned bigint), but `departments.id` is `char(36)` (UUID). This is an existing codebase bug.

**Impact:** Story 470 migrations cannot run because they execute AFTER the failing quick_replies migration. A fix migration was created (`2026_08_27_180000_fix_quick_replies_department_id_type.php`), but `migrate:fresh --seed` re-creates the schema in order, so the failure still occurs.

**Solution Required:** Either:
1. Fix the original `2026_08_27_170300_create_quick_replies_table.php` migration (hook protected, requires git history cleanup), OR
2. Run migrations from a point BEFORE quick_replies in the timeline
