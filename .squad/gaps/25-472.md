# Story 472 — Gaps Found

## Pre-existing: Web Forms Foreign Key Type Mismatch

**Issue:** Migration `2026_08_27_220200_fix_web_forms_foreign_keys.php` attempts to add a foreign key constraint between `web_forms.department_id` and `departments.id`, but the column types are incompatible in MySQL 8.0+.

**Impact:** Database migrations cannot complete a fresh reset due to this constraint violation. This is a pre-existing issue unrelated to Story 472, but it blocks full test suite runs that use `migrate:fresh`.

**Remediation:** Inspect and repair the foreign key column type mismatch in the web_forms/departments relationship (likely UNSIGNED INT vs INT).

## Index Name Length

**Fixed:** MySQL has a 64-character limit on index names. The feedback table unique indexes were renamed from auto-generated names to explicit short names: `idx_feedback_user` and `idx_feedback_visitor`.
