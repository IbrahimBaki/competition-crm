## Items NOT IN ORIGINAL PLAN (discovered during implementation)

### 1. Model Import Issues
**Issue**: BilingualStringCast imports were stripped by post-hooks on some models.
**Solution**: Manually re-added imports to Branch, Department, Team, BranchHoliday models.
**Future**: Consider hook configuration to preserve use statements.

### 2. Exception Constructor Batch Refactoring
**Issue**: 11 Security exceptions had no constructors to capture translated messages.
**Solution**: Added constructors to all exceptions with appropriate translation keys.
**Pattern**: All exceptions now call `parent::__construct(__('errors.security.key'))` to resolve messages at throw time.

### 3. Mail Locale Parameter Syntax
**Issue**: `__()` function in envelope() doesn't support direct `locale` parameter in Laravel 11.
**Current**: Uses `app(LocalizationSettings::class)->defaultLocale()` to get default locale for mail.
**Enhancement**: Could be improved to use recipient's locale if available via User model lookup.
